# Employee File Handling & Serialization (Java)

## 📌 Project Overview
This Java application demonstrates file handling and object serialization using a simple Swing-based user interface.

The application:
- Reads employee data from a text file
- Serializes the employee objects into a binary file
- Deserializes the objects
- Displays the employee details in a GUI

---

## 🛠 Technologies Used
- Java
- OOP Concepts
- File Handling (BufferedReader)
- Serialization (ObjectOutputStream, ObjectInputStream)
- Java Swing (GUI)
